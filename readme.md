# Cow Facial Recognition using YOLO and ImageNet

This repository contains a fine-tuned YOLO model designed for cow facial recognition. The model has been trained and optimized to identify and recognize individual cow faces with high accuracy.

## Features
- **Fine-Tuned YOLO Model**: Leveraging the YOLO architecture for real-time object detection and recognition.
- **Cow Face Identification**: Capable of identifying and distinguishing individual cow faces.
- **ImageNet Pretrained Weights**: Utilizes pretrained weights from ImageNet for enhanced performance.
